# FIFA World Cup 2026

Static fan site for the FIFA World Cup 2026, plus an interactive phone demo. No install, no build step, and no secrets.

## Run

From the repo root:

```bash
python3 -m http.server 8080
```

- Site: http://localhost:8080/
- Interactive demo: http://localhost:8080/demo.html

You can also open `demo.html` on a chosen screen, for example http://localhost:8080/demo.html?screen=tickets.

The demo is a phone you tap through. Home, teams, players, matches, the stadium, and tickets are connected. Screens change only when you click or tap — nothing autoplays.
